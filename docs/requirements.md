# 需求冻结说明

> 决策来自需求讨论；变更先改本文档再改代码。

## 业务目标

收集真实攻击者对 **SOCKS5 / HTTP 代理** 爆破时使用的用户名与密码，按端口与协议沉淀密码本；长期运行并支持 Web 查看。

## 已确认决策

| # | 项 | 决策 |
|---|----|------|
| 1 | 部署 | 海外云主机 |
| 2 | 协议 | 仅 SOCKS5、HTTP 代理、HTTPS 语义（CONNECT）；不做 FTP/21 |
| 3 | 存储 | JSONL（真相）+ SQLite（查询） |
| 4 | 端口协议 | `primary` + 首包自适应；便于清洗 |
| 5 | 语言 | **Python** |
| 6 | Web | 公网可访问；**暂不强制 TLS**；用户名密码 Session；环境变量配置 |
| 7 | 端口管理 | 支持新增蜜罐端口（配置 + Web 动态） |
| 8 | 伪装 | L1 默认；L2 可选；**L3 禁止** |

## 初始端口（示例，可改）

1080, 1081, 10801, 10808, 10809, 9050（socks5 优先）  
3128, 8888, 7890, 7891, 2080, 3080, 32080, 7777, 20001–20003, 20201–20202（http_proxy 优先，also socks5）

## 成功标准

- 稳定记录 `(username, password, port, protocol, src_ip, ts)`
- 可导出 Top 密码本
- Web 可看趋势与动态加端口
- 被扫时服务不倒、无出站转发
